# 驻马店教育局端：托管活动评价明细

基于截图搭建的静态交互原型，无需安装依赖。使用标注的示例数据，未接入后端。

- 新菜单位于“报表管理 > 报表汇总”下方。
- 活动列表支持活动名称搜索、起止日期筛选和重置，展示活动名称、服务组织（机构或基地）、参与学校数量、已评学生数、未评学生数及查看详情入口。
- 学生明细页支持学校名称模糊搜索、学年、学期、年级、班级组合筛选，查询与重置按钮和筛选条件同行。
- 学生列表每人一行：学生姓名、学校名称、年级、班级、区县教育局、活动名称、操作。可导出当前筛选结果为 CSV。
- 点击学生行“查看详情”打开弹窗，展示该活动的两级评价指标、星评或分值，以及独立的活动评语。部分一级指标无二级，部分含两个二级指标。
- 星评不显示分数；分值显示实际分数，五星按满分比例填充，支持半星。弹窗支持关闭按钮及 Esc 关闭。
- 点击“报表汇总”可查看截图学生明细参考页，支持姓名查询和示例 CSV 导出。

本地预览：在仓库根目录执行 `python3 -m http.server 4178 --bind 127.0.0.1`，访问 `/projects/custody-activity-evaluation/`。

公网预览：https://waynewcheung9266.github.io/yunyingchanpinzu/projects/custody-activity-evaluation/

区县教育局列位于班级后，缺失或空白时显示“- -”，导出保持相同规则。

活动列表不创建导出按钮；评价详情弹窗在活动名称下一行展示对应的服务组织（机构或基地）。

页面最右侧固定悬浮高亮“需求说明”按钮（位于列表外），点击右侧抽屉展示市教育局及区县教育局的统计来源说明。支持关闭按钮、点击遮罩及 Esc 关闭。
