# 驻马店教育局端：托管活动评价明细

基于截图搭建的静态交互原型，无需安装依赖，未接入后端。当前记录均为演示数据。

页面流程：活动列表 → 学校评价明细 → 所选学校的学生评价明细 → 学生评价弹窗。

- `index.html`：活动名称、起止日期筛选。列表展示活动名称、服务组织（机构或基地）、参与学校数量、已评学生数、未评学生数、查看详情。不显示导出。
- `schools.html?activity=1`：仅支持学校名称模糊搜索；列表展示学校名称、区县教育局、查看详情。不显示导出。
- `detail.html?activity=1&school=学校名称`：限定当前活动与所选学校，筛选项仅年级、班级。每名学生一行，展示学生姓名、学校名称、年级、班级、区县教育局、活动名称、查看详情。支持导出当前学校及筛选范围的 CSV，重置不改变学校范围。
- 区县教育局缺失时显示“- -”，导出遵循同一规则。
- 学生评价弹窗顶部以浅蓝色信息区展示学生、学校、年级班级、活动名称、服务组织；下方展示两级指标及评价结果，底部独立展示该学生的活动评语。仅部分一级指标含二级。
- 同一活动统一使用星评或分值，示例第1/3个活动为分值，第2/4个活动为星评。均显示五角星，分值显示实际分数并按满分比例填充，星评无分数字样。
- 每页最右侧固定悬浮“需求说明”按钮，打开同一份统计来源抽屉，支持关闭按钮、遮罩及 Esc 关闭。
- 筛选的查询、重置按钮同行靠右；保留侧栏折叠，以及报表汇总的截图参考页面。

本地预览：在仓库根目录执行 `python3 -m http.server 4178 --bind 127.0.0.1`，访问 `/projects/custody-activity-evaluation/`。

公网预览：https://waynewcheung9266.github.io/yunyingchanpinzu/projects/custody-activity-evaluation/

学校页标题为“学校列表”，学校模糊搜索位于列表表头最右侧，输入或清空即时筛选。按最新展示要求，刘同学单独使用星评作为对比示例，弹窗中所有指标都显示“星评”和五星，无分数；其他学生沿用活动设定。

评价模块顶部提供“学生评活动 / 学校评机构”切换。school-organization.html 预留筛选和列表区域，具体业务字段待补充；需求说明仍可用。活动列表新增活动创建方筛选（机构端、基地端、运营端），列表在服务组织前显示活动创建方，支持与活动名称和日期组合筛选。

学校评机构页已复用活动列表的筛选和表格结构。仅保留机构端、运营端及机构服务组织，按学校评价状态统计已评学校数和未评价学校数，不展示参与学校数及学生评价数量。示例中秋季托管劳动实践活动已评2校、未评价1校，托管阅读分享活动已评0校、未评价1校；详情暂保留占位弹窗。

学校评机构详情弹窗复用学生评活动的两级指标、五星评价结果与活动评语结构及浅蓝色信息区。头部依次显示活动名称、活动创建方、服务组织、评价教师；教师和评价内容为演示数据。

学校评机构的评价示例：秋季托管劳动实践活动使用分值；托管阅读分享活动使用星评，同一活动所有指标统一模式。

学校评机构流程更新为：school-organization.html 活动列表 → organization-schools.html 学校列表 → 学校评价详情弹窗。学校列表复用学校名称、区县教育局、操作结构及表头右侧学校模糊搜索，新增导出报表，导出当前筛选学校。弹窗保留活动名称、创建方、服务组织、评价教师及两级指标、星评/分值、评语。两类活动页标题统一为“活动列表”。

学校评机构的学校列表表头顺序为学校搜索、导出报表。评价弹窗按学校实际评价状态分支，未评价学校只展示顶部活动信息与“老师暂未评价”占位图，不展示指标、评价结果或评语；已评价学校保持正常详情。

学校评机构页面统一使用“服务机构”称呼，学校列表在区县教育局之后展示服务机构，导出同步包含此列，名称取自当前活动关联机构；学生评活动仍保留“服务组织”（涵盖机构和基地）。

学校评机构的学校列表在服务机构后增加活动名称，导出同步包含活动名称。两类评价的学校页及学生页，返回链接后不再附带活动名称。
